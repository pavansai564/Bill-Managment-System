Payment Receipt Generator
This is a simple Python application created using the Tkinter library that allows users to generate a receipt based on selected items, their prices, and quantities.

Features:
Item Selection: Users can select from a list of predefined items (Coca Cola, Bun, Chicken Fry, Roll, Fish Fried Rice).
Price and Quantity Entry: For each selected item, users can input the price and quantity.
Receipt Generation: Once items, prices, and quantities are selected and entered, users can print a formatted receipt displaying the item details and total amount.

Requirements:
Python 3.x
Tkinter (comes pre-installed with Python)

Installation:
Make sure you have Python 3.x installed on your system.
Clone this repository or download the source code.
Navigate to the directory where the code is located.

How to Run:
Run the application using the following command:
bashCopy codepython receipt_generator.py
(Ensure to replace receipt_generator.py with the actual name of your Python file, if different.)
Usage

Select the items you wish to purchase by checking the corresponding checkboxes.
Enter the price and quantity for each selected item.
Click the "Add" button to insert the items into the receipt list.
Click the "Print" button to generate and display the receipt in a new window.

The receipt will display:
Item names
Prices
Quantities
Total for each item
Grand total of all items
